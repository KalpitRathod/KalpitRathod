# Hi there 👋, I'm Kalpit Rathod

I'm a **Systems Programmer & Edge AI Architect** passionate about low-level computing, Linux kernel internals, and hardware-accelerated on-device AI. I focus on bridging software and silicon—from writing Linux device drivers in **C/C++** to engineering production-grade on-device AI runtimes using **ARM NEON SIMD**, **llama.cpp**, and **Kotlin** on Android.

---

### 🚀 What I'm Focused On

- 📱 **On-Device & Mobile AI:** Creator of **[MobileAI Framework](https://github.com/KalpitRathod/MobileAIFramework)** — a hardware-aware on-device AI runtime delivering CPU Big-Core thread pinning, dynamic thermal scaling, SQLite vector search (RAG), ~30ms offline vision OCR, and autonomous phone agents on Android.
- 🐧 **Linux Kernel & Systems Engineering:** Authoring **Linux Device Drivers (LDD)**, socket networking utilities, and practicing low-level POSIX systems programming (**APUE**).
- 🤖 **Autonomous Agents & Multimodal Edge Systems:** Orchestrating small language models (SLMs) to execute real-world OS tasks via Android accessibility services and edge vision pipelines.
